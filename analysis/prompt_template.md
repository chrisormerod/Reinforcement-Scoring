# Prompt template for the generative arms (G1–G6)

Model: `Qwen/Qwen3.5-4B`. The encoder arms (E1–E11) have no prompt: ModernBERT reads the raw `EssayText`.
Source: `src/gen_common.py` (`format_suffix`, `DECODING`), `src/gen_local.py` (`prompt_text`, `answer_suffix`).

## Chat structure

| Role | Content |
|---|---|
| system | `{rubric}` + a blank line + `{suffix}` |
| user | the student response (`EssayText`), used as-is |
| assistant | generated by the model (G5 training: `Answer: {score}` with the gold score, loss on these tokens only) |

```
[system]
{rubric}

{suffix}

[user]
{EssayText}
```

## Suffix

The suffix is fixed and never optimized, so MIPROv2 cannot change the score range. `{scores}` is the set's own score list (set 1: 0, 1, 2, 3).

| Arms | Suffix |
|---|---|
| G1–G4, G6 | `Reply with only the integer score: one of {scores}.` |
| G5 | `Reply in the form "Answer: <score>", where <score> is one of {scores}.` |

## Rubric

| Arms | Rubric source |
|---|---|
| G1, G2 | original human rubric, `data/rubrics_md/rubric_<k>.md`, used as-is (including its header table) |
| G3, G5 | MIPROv2-optimized rubric from G3 (original where optimization fell back): `results/G3/default/seed0/set<k>/rubric.md` |
| G4, G6 | MIPROv2-optimized rubric from G4 (original where optimization fell back): `results/G4/default/seed0/set<k>/rubric.md` |

## Mode and decoding

| Arms | Thinking | Decoding |
|---|---|---|
| G1, G3, G5 | off | greedy (temperature 0), 64 max tokens |
| G2, G4, G6 | on | temperature 0.6, top-p 0.95, 16,384 max tokens |

## Parsing

The first integer in the reply is the score. A score outside the set's range, a truncated reply, or a reply with no integer is a parse failure. Failures are re-sampled up to 3 times (retry rule of PROJECT.md §6.6).
